# Tape Loss

A lo-fi tape effect that runs in the browser: wow, flutter, saturation, loss, dropouts and hiss, a
granular section, a reverb and a small master section. Sound comes from a live input, a recorded
loop or an audio file.

Open it: https://thegoose12.github.io/tape-loss/

- Made for an iPad on its side. Add it to the Home Screen to run it full screen; after the first
  visit it also opens without a network.
- Live input, Rec and Thru use the device's audio input, so the browser asks for microphone access.
- The Skin key switches between three faces: Reel, Cassette and Unit.
